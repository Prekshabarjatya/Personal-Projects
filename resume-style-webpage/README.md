# 🌐 Personal Resume Website

A beginner-friendly **resume website** built with **HTML5** and **CSS3**.  
The goal of this project is not just to build a static page, but to practice writing **semantic HTML** and ensuring **basic accessibility** so the site is usable by everyone.

---

## 📝 Project Brief
This project is a **personal resume/portfolio page** that contains:
- An introduction (About Me)
- Education history
- Skills showcase
- Project highlights
- Contact information  

It emphasizes clean structure, semantic elements, and accessible markup.

---

## 🛠️ Tech Stack
- **HTML5** – semantic structure (header, nav, main, section, footer, etc.)  
- **CSS3** – layout and styling with responsiveness  

---

## 🔑 Core Features
- **Semantic HTML**  
  - Proper use of `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`  
  - Descriptive elements like `<address>`, `<abbr>`, `<strong>`, and `<em>`  

- **Accessibility**  
  - Navigation with clear landmarks (`aria-label`)  
  - Proper heading hierarchy (`h1`, `h2`)  
  - Accessible links (`mailto:`, `tel:`)  
  - Color contrast and readable font sizes  

- **Responsive Design**  
  - Flexible sections that adapt to different screen sizes  
  - Clean typography and spacing for readability
